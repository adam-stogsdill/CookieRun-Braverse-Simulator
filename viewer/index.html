    Who is playing?
    
    
    A profile is one encrypted file on this machine. It keeps
       your games, how each deck has done and your level — and it goes nowhere
       else. Give it a passphrase and nothing but that passphrase opens it;
       leave it blank and it is unlocked by a key kept beside it, which keeps
       the file private in a backup but not from someone sitting here.
